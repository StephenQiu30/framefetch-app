# 信息架构与导航

- **公开首页**（未登录）：与 Web 共用内容基线（标语“把素材，带回本地。”、开源自托管定位、解析／选择／执行／交付四步、产品能力、技术栈、安全边界、FAQ、使用指南 `/guide`、源码与部署入口）；仅静态介绍，不调用需 Token 的接口。中英文文案在 ARB。
- **登录后一级导航**（底部，五项）：首页、下载记录、剧本文档、平台状态、我的。选中项显示图标与标签，未选中项保持图标与稳定触控宽度，大字体下仅显示当前标签，其余保留完整读屏名称。
- **顶部栏**：只保留“帧取”文字品牌与明暗主题按钮（≥ 44×44）；详情与管理子页使用显式返回按钮，有栈则 `pop`，无栈用页面声明的安全回退地址（下载详情→首页，管理子页→管理中心，管理中心→首页）。列表进入详情一律 `push`，返回保留标签页、表单与滚动上下文。
- **首页**：链接解析／本地视频／剧本文档三种入口（无卡片分段切换，大字体下纵向全宽）。“我的”承载账号身份、管理中心入口（管理员）与退出登录，退出始终是最后一个操作（全宽危险色文字按钮）。
- **主题**：仅浅色／深色两态，一键切换，首次安装浅色；偏好用 `shared_preferences` 保存，不与认证凭据共用存储；公开页、认证页与所有登录后页面共用同一入口。
