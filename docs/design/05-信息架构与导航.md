# 信息架构与导航

- **公开首页**（未登录）：与 Web 共用内容基线（标语“把素材，带回本地。”、开源自托管定位、解析／选择／执行／交付四步、产品能力、技术栈、安全边界、FAQ、使用指南 `/guide`、源码与部署入口）；仅静态介绍，不调用需 Token 的接口。中英文文案在 ARB。
- **登录后一级导航**（底部，五项）：首页、下载记录、剧本文档、平台状态、我的。每项保留图标与标签，选中态以文字与图标样式区分；标签缩放上限为 1.3，稳定保留 ≥ 44pt 触控区域和完整读屏名称。页面正文仍跟随系统字体缩放。
- **顶部栏**：64pt 高，使用与 Web 相同的图形 Logo 和“帧取”文字品牌、明暗主题按钮与资源菜单（≥ 44×44）；资源菜单中的使用指南、自托管部署、关于对匿名与登录用户可达。详情与管理子页使用显式返回按钮，有栈则 `pop`，无栈用页面声明的安全回退地址。列表进入详情一律 `push`，返回保留标签页、表单与滚动上下文。
- **首页**：链接解析／本地视频／剧本文档三种入口（大字体下纵向全宽）。“我的”承载个人资料、头像管理、统一处理记录、资源、管理中心入口（管理员）与退出登录，退出始终是最后一个操作。统一处理记录 `/history/activity`，历史解析结果 `/download-intents/:intentId`，独立分析结果 `/analyses/:analysisId`。
- **主题**：仅浅色／深色两态，一键切换，首次安装浅色；偏好用 `shared_preferences` 保存，不与认证凭据共用存储；公开页、认证页与所有登录后页面共用同一入口。
