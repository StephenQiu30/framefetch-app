# 链接解析与下载

## 链接解析与下载创建

- 输入原始链接或整段分享文案，保留原始换行；服务端提取并校验恰好一个 HTTP(S) URL（客户端只拒绝空输入）。
- 采用服务端持久解析意图：`POST /api/download-intents`（UUID 幂等键）→ 按意图 ID 轮询。响应不明时先以幂等键只读 GET 收敛，不自动重发；404 后用户显式重试才复用同一键。历史列表从 `GET /api/download-intents/history` 游标分页，账号变化立即清除；进程内只存 ID 与状态，不持久化原文、Cookie 或媒体直链。
- 状态：仅 `ready`、inspection 未过期且 `downloadable` 才可确认格式；结果过期显示显式“更新”（`POST /{id}/refresh` 保留原意图，开启新 generation 并重新确认，不自动下载）；`handed_off` 进入下载详情。公众号文章先来源发现，多候选由用户选择。
- 平台来源和执行上下文由服务端确定。`queued/resolving` 只观察原意图并允许取消，`cancelling` 持续轮询直到清理确认，不重复取消、刷新或创建任务；恢复不延长原截止。类型化 `failure` 展示实际根因，身份不可用不等于本站登录失效。已就绪结果过期后可显式刷新；失败、超时或取消后可重新创建任务，取消后的原意图不能刷新。`context_changed` 要求重新解析并确认规格。服务端架构、阶段计划和真实验收只维护在 [解析引擎重建设计](../../../video-server/docs/design/17-解析引擎重建.md)，本文只规定 App 消费契约。
- 解析截止限制服务端执行，不代替服务端终态。截止后与临时 GET 故障采用 5 秒只读收敛，继续读取原意图直到终态；明确的资源或身份拒绝停止查询。前台恢复同样 GET 原意图，不能重新接单或自动刷新 generation。
- 输入变化立即清除旧解析、候选、选中格式与错误；解析、候选选择、创建互斥；格式清单不在客户端改写，放入最高 360px 的独立滚动区，默认选中服务端第一项；非 `downloadable` 直接显示服务端 `user_action`／`restriction_reason`。
- 轮询仅在非终态运行，间隔与后台恢复有界，回前台用 GET 更新；在途请求按意图代次隔离；创建下载成功后使历史失效并 `push` 到 `/downloads/{jobId}`。
- 保留的同步 inspection 路径仅用于文章／明确权限，过期时清除旧规格与幂等键并要求重新解析。

## 下载历史与详情

- 历史：服务端分页（每页 20）、搜索、状态筛选，筛选变化回第一页；列表 16:9 封面 + 标题／来源／格式 + 状态。列表项整行可点，向左轻扫显示删除，页面以弱化提示说明手势，并提供独立读屏删除动作（≥ 44px）。
- 详情：标题、来源、格式、状态、阶段、进度、执行次数、文件可用性与时间、归类后的失败原因；活跃任务（`queued/running/retry_wait`）每 2 秒 REST 读取，终态停止；支持取消、重试、获取文件、观看、删除、进入分析。本地导入的失败／取消／制品缺失提示回首页重选文件；远程下载保留重试。幂等键由应用操作持有，不确定响应复用 key，确认成功或会话变化换 key，并发点击共享 Future。
- 私有封面通过生成客户端 + Bearer 读取为内存字节，路径限于服务端返回的 thumbnail 路径，不把 Token 写入图片 URL，按资源路径内存缓存。
- 短时下载／播放地址按操作即时签发（`POST /api/downloads/{job_id}/download-url`），不持久化、不记录日志。“观看”应用内播放，“获取文件”交给系统浏览器处理 `Content-Disposition: attachment`。详情标题最多三行，完整标题保留在语义树。
- 平台状态：`GET /api/providers`，登录后立即预取并按会话缓存（后端约 2 秒），切 Tab 不销毁数据，下拉刷新保留现有内容；提供全部／可用／需要关注筛选与平台证据详情；冷启动用骨架占位。

## 平台策略选择

解析选项消费服务端允许的策略、默认值与 hosts；改变策略清除旧解析并改变幂等指纹；未配置的选项禁用，未准入访客不提供选项。
