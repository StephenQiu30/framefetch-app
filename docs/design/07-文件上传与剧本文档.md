# 文件上传与剧本文档

## 文件上传

- 视频仅 MP4，剧本仅 DOCX／PDF／TXT／Markdown／Fountain，文档 ≤ 50 MB。文件由系统选择器授权，不申请相册或全盘权限，不持久化路径、上传 URL、Token 或内容。
- 流程：本地校验 → 流式 SHA-256 → 创建受限上传会话 → 向会话返回的预签名 URL 分片 PUT（校验分片数、顺序、过期与 ETag，隔离的 Dio 实例，不附带 Bearer）→ 完成请求。视频完成进入下载详情，剧本完成切到文档页并刷新。
- 预算：分片连接 15 秒、发送 2 分钟、接收 30 秒，且不超过会话剩余期限；分片阶段最多 15 分钟，整个上传最多 30 分钟；任一分片失败立即取消其余。创建与完成请求接收 CancelToken，创建幂等键在认证重放时稳定；提供“取消上传”，迟到进度／结果不覆盖新操作，退出与会话切换取消上传，清理最多等待 5 秒，其余由服务端过期兜底。不将完整视频载入内存。

## 剧本文档

- 列表分页（删除末项后仍可翻回前页），“本页可用”明确标注为本页数量；`/documents/:documentId` 类型化详情路由，`uploading`／`verifying` 每 3 秒轮询，终态停止。
- 详情展示状态、文件名、格式、语言、场景数、字符数、导入版本、大小、时间、解析摘要、质量提示与规范化正文（Markdown：转义 HTML、禁用外链、可选择）。手机宽度长指标两列，大屏四列。
- 删除覆盖原文件、规范化文本与记录，正在进行的分析须先结束；收到 `204` 才刷新或离开，失败保留现状并可重试；`409 invalid_state` 明确说明被分析占用。
