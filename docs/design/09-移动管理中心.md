# 移动管理中心

## 移动管理中心（仅管理员）

覆盖五类数据：下载分析（周期切换、独立用户、取消数、平均时长、来源指标与每日文本明细，不引入图表依赖）、文件（分页、类型、1–3650 天清理，明确永久删除与活动分析跳过）、用户（分页、搜索、身份与启用筛选，不能修改自己的管理员权限）、平台目录（搜索、公开筛选、新增／编辑／删除，系统条目保留删除限制，表单明确目录配置不新增下载能力）、AI 服务（新增／编辑／删除、线路激活，API Key 不读回、不记录，保留内置 Codex 规则）；另有服务端只读运行诊断（配置／上下文不等于下载成功）。写操作成功后重新读取服务端列表，失败保留内容并重试，403 映射为无权限。
