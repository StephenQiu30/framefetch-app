# 移动管理中心

## 范围与权限

移动管理中心与当前 Web 管理端共享服务端契约，覆盖使用统计、文件、用户、平台目录、AI 服务及系统操作日志。只有已登录管理员能够进入管理路由；403 映射为无权限，鉴权与会话刷新继续使用 App 原生令牌链路。

页面使用全局 shadcn 语义 Token、无边框布局和 Phosphor 图标，支持深浅主题、可访问字体和可用宽度驱动的重排。可见文案进入 ARB。列表默认每页 10 条，并提供 10／20／50；用户、文件和日志通过服务端分页，平台目录与 AI 配置在完整查询结果上筛选和分页。筛选或每页条数变化时回到第一页。

## 使用统计

使用统计提供下载与 AI 分析两个标签，共用最近 7／30／90 天周期，显示服务端窗口的 UTC 日期。两个数据源按当前标签独立读取，覆盖加载、重试、空结果和请求失败。

- 下载：每日全部／成功任务趋势、周期下载总数、服务端成功率、独立用户、下载数据量与平均视频时长、状态分布、每日完成率、来源占比及各来源的精确状态、用户与数据量。
- AI 分析：每日全部／成功执行趋势、执行次数、成功率、平均完成耗时、有效耗时样本数、进行中数量、执行状态与视频／剧本输入分布。

AI 分析按 `analysis_run.created_at` 所属 UTC 日期统计当前状态。手动重试和重新分析各计一次执行；执行次数不代表模型请求次数、Token 或费用。客户端成功率为成功 ÷（成功 + 失败），没有成功或失败样本时显示缺失值。平均耗时直接使用服务端数据，仅统计具有有效开始与结束时间的终态执行，包含执行内重试和报告发布；服务端返回 null 时显示缺失值。

趋势图通过线性区段连接数据，提供触控、键盘和读屏日期选择；精确逐日数据可展开。图表直接消费共享 `chart-1` 至 `chart-5` 颜色，并以原生绘制实现，不引入第二套图表或动画依赖。

## 文件与用户

文件列表展示类型、对象数、大小与创建时间。持久文件不会自动过期，管理员可以确认后删除单个文件；App 不提供所选文件删除或按天数批量清理。单个正在分析的源文件不能删除；单条删除保留失败反馈、会话检查和重复提交防护。

用户列表提供搜索、角色和启用状态筛选，展示注册时间与配额豁免状态。编辑涵盖角色、启用状态、用量豁免、同时活跃任务、24 小时任务数、24 小时处理量、保留存储与 24 小时分析尝试。留空表示使用系统默认；GiB 输入转换为服务端整数 Byte，并校验正数及整数任务额度。保存成功后关闭表单并重新查询；失败保留编辑内容。

当前登录管理员不能在此修改或删除自身。删除账户会移除账户、登录凭据、角色、配额和会话，历史下载文件与任务记录不会自动删除。

## 平台目录与 AI 服务

平台目录支持搜索、公开／隐藏筛选、新增、编辑、公开状态调整以及单条删除。名称、排序与公开状态由目录条目管理。删除系统已注册平台的目录条目只影响目录和公开状态页，系统下载 Profile 继续保留；新增“仅目录”条目不会增加下载域名、执行能力或平台身份。

AI 服务支持搜索、新增、编辑、线路激活、单条删除，并展示引擎、模型、认证方式、凭据状态和 Agent 可用性。只允许一个当前分析线路；当前线路和 `local-codex` 系统兜底线路不可删除。`local-codex` 只允许修改显示名称和模型。

- Codex CLI 使用 Responses 语义，Claude CLI 使用 Messages 语义；两者支持宿主账号登录或 API Key。
- OpenRouter、OpenAI 兼容 API 和 DeepSeek 直连引擎仅支持 API Key。
- 切换引擎或认证方式时清空输入凭据并应用对应 API 地址，不填入未经选择的 Codex／Claude 默认模型。
- OpenRouter 固定为 `https://openrouter.ai/api/v1`；模型目录仅列出声明支持文本输入、文本输出和结构化输出的模型，并标识图像支持。视频分析应选支持图像的模型，目录能力不代表真实调用已验证。
- DeepSeek 视觉适配器固定使用 `deepseek-v4-flash-vision-exp`，模型字段不可修改。
- 公网 API 地址要求 HTTPS；明确的 localhost／127.0.0.1／::1 可用 HTTP。地址不得包含用户信息、query 或 fragment。
- API Key 保存后只显示已配置状态，不读回或记录明文。保留空凭据只适用于认证方式、引擎与规范化地址保持一致的已配置线路；改变凭据上下文需要重新输入。

## 系统操作日志

日志展示系统业务请求、管理员操作与系统任务状态。支持操作人／操作名称搜索、全部／接口请求／系统任务／管理员操作范围、执行结果和开始／结束时间筛选。时间按设备本地时区输入，再转换为 UTC；结束筛选包含所选整分钟。非法日期或反向时间范围阻止请求并显示校验反馈。

日志列表显示时间、操作人、操作名称、对象和结果，详情为只读记录，包含日志 ID、账户 ID、操作标识、接口、对象标识、发起／结束时间、HTTP 状态与错误码。请求结果与任务状态分别展示；`started` 表示结果尚未确认，不能显示为成功。日志只覆盖日志功能启用后的操作。

## 单条写入与验证边界

管理页不提供复选框、选择集合、全选或批量工具条。删除使用生成客户端的单项删除接口，遵守用户自身及 AI 当前／兜底线路限制；失败保留原记录并反馈原因。筛选和写入控件在处理期间防止重复操作，用户与文件删除后校正末页，写入结束后重新读取服务端列表。

单条操作固定开始时的账户与会话代次，请求前后检查会话及页面所属状态。退出、切换账户、权限降级或页面卸载后，旧响应不能覆盖新会话数据或修改新页面的分页；管理查询重新读取。已发送的单项删除可能已在服务端完成，停止后不自动撤销。

自动化验证包括生成客户端线协议、单条写入失败和防重复、会话隔离、时间区间、AI 协议校验，以及 390 宽度和 2 倍文字下的统计／日志正常、空、失败与详情状态。原生截图测试使用合成数据，仅证明原生渲染与交互；真实管理写入、真实模型执行和管理员业务 E2E 必须通过隔离环境另行验收，不以合成数据、只读运行诊断或服务就绪代替。
