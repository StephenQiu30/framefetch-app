# 服务契约

- **唯一来源**：从 `video-server /openapi.json` 按声明式白名单冻结到 `contracts/openapi/video-server.openapi.json`（`dart run tool/openapi.dart`），再生成 `packages/video_server_api/`；CI 校验无漂移，生成代码不手改。当前冻结 48 个路径、56 个 App 操作。
- **覆盖**：原生认证、来源发现、媒体解析、持久解析意图、下载创建、视频与剧本文档上传与删除、下载历史与详情、剧本文档详情与规范化预览、私有封面、短时下载地址、取消／重试、视频与剧本 AI 分析、平台状态、用户资料，以及管理员的下载分析、文件、用户、平台目录与 AI 线路操作，报告 DOCX 导出，管理员只读运行诊断。WebSocket Token 更新未冻结，实时状态一律以 REST 轮询收敛；未冻结的操作 fail closed，不显示模拟结果。
- **响应包装**：共享业务接口保留 `{code, message, data}`，Repository 在数据边界解包并校验 `data`（页面不感知包装，不通过拦截器篡改响应体）；`/api/app/v1/auth/*` 是直接响应，不套包装。错误统一读取 `code/message/data`（兼容旧 `detail` 仅作回退），并分类为认证、权限、限流、服务不可用、离线、超时、`invalidResponse`（契约不匹配，不得提示“检查网络”）等，页面只看分类后的失败。
- **可选查询参数**：冻结器把 nullable 标量规范为可省略参数，避免生成器把未选条件编码为空字符串；`false` 与枚举按原值发送。
- **服务地址**：构建期注入 `VIDEO_SERVER_BASE_URL`，默认 iOS 模拟器 `http://127.0.0.1:8111`，Android 模拟器 `http://10.0.2.2:8111`；生产必须 HTTPS。开发直接连接本机 `video-server`，不使用 Docker。
- **超时**：连接预算 30 秒（真机中继链路），解析请求接收超时 185 秒（覆盖服务端 180 秒预算），不做 UI 层自动重试、证书例外或 IP 回退。
