# 服务契约

- **唯一来源**：从 `framefetch-server /openapi.json` 按声明式白名单冻结到 `contracts/openapi/framefetch-server.openapi.json`（`dart run tool/openapi.dart`），再生成 `packages/framefetch_server_api/`；CI 校验无漂移，生成代码不手改。冻结范围以白名单和生成快照为准。
- **覆盖**：原生认证与注册邮箱验证、来源发现/恢复、媒体解析、持久解析意图、下载创建、视频与剧本文档上传与删除、下载与统一处理记录历史、分析运行与关联处理记录、剧本文档详情与规范化预览、私有封面、短时下载地址及流式下载、取消／重试、视频与剧本 AI 分析、平台状态、用户资料和头像，以及管理员的下载/AI 分析统计、操作日志、文件删除、用户配额与删除、平台目录、AI 线路、OpenRouter 模型和引擎能力，报告 DOCX/Markdown 导出，管理员只读运行诊断。WebSocket Token 更新未冻结，实时状态一律以 REST 轮询收敛；未冻结的操作 fail closed，不显示模拟结果。
- **响应包装**：共享业务接口保留 `{code, message, data}`，Repository 在数据边界解包并校验 `data`（页面不感知包装，不通过拦截器篡改响应体）；`/api/app/v1/auth/*` 是直接响应，不套包装。错误统一读取 `code/message/data`（兼容旧 `detail` 仅作回退），并分类为认证、权限、限流、服务不可用、离线、超时、`invalidResponse`（契约不匹配，不得提示“检查网络”）等，页面只看分类后的失败。
- **可选查询参数**：冻结器把 nullable 标量规范为可省略参数，避免生成器把未选条件编码为空字符串；`false` 与枚举按原值发送。
- **联合与文件响应**：必填且唯一 `record_type` 的记录联合以等价 `oneOf` 和 discriminator 生成，保留视频/剧本分析各自的模型；其他可空或重叠联合保持不变。报告、头像、缩略图和下载以生成客户端的二进制接口消费，头像上传发送原始 body；报告保存/分享获取服务端 Markdown 原文，不从预览文本重建制品。
- **服务地址**：构建期注入 `FRAMEFETCH_SERVER_BASE_URL`，默认 iOS 模拟器 `http://127.0.0.1:8111`，Android 模拟器 `http://10.0.2.2:8111`；生产必须 HTTPS。开发直接连接本机 `framefetch-server`，不使用 Docker。
- **超时**：连接预算 30 秒（真机中继链路），解析请求接收超时 185 秒，不做 UI 层自动重试、证书例外或 IP 回退。

解析结果与下载提供可空、只读的 `execution_context`，只含服务端定义的非敏感摘要；本地导入或未执行时可为 null。平台身份声明为 `none/prefer/required`，App 仅展示声明和实际上下文，不读取账号材料或设置平台策略。prefer 表示身份不可用时匿名解析继续，下载保持解析时的身份选择。
