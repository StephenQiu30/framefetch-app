# AI 分析与报告

## AI 分析

- 视频、剧本与文字创作历史共用控制器（`AnalysisTarget` 区分），契约：Skill 清单（`input_kind`）、创建、恢复、读取、取消、重试、删除，创建／重试使用稳定幂等键。
- 下载成功后才展示分析区；实际可执行的方法以服务端清单为准；可执行方法包含逐镜拉片（`video-shots`）、公众号成稿（`video-to-article`）、成片审阅（`video-review`）、素材拆解（`video-breakdown`）、剧本审阅（`screenplay-analysis`）及文章／公众号／小红书整理（`article-format`、`wechat-format`、`xhs-format`），其他原方法不因此视为已启用；默认选中适用的第一项，可选输出语言，编辑分析重点（≤ 4000 字）。分析状态独立于下载状态；活跃分析每 2 秒 REST 收敛；每次操作、Provider 重建或销毁使旧请求代次失效，旧结果不写回也不恢复轮询；`runNo/version` 不回退；已完成任务可重新分析并标识“上一版”结果。源文件结果区提供“新建创作任务”，读取当前方法清单并保留旧结果，再按新用途创建独立任务；精确历史详情保持原方法重跑语义。
- 结果按服务端判别联合渲染视觉分析、视频文章、结构化报告、剧本分析、剧本改写与文字创作；长结果一次一个分类，避免同时构建全部分镜。视觉结果包含优先分镜、延展建议、场景视觉规则／连续性风险、分镜叙事作用／转场、资产证据分镜；视频文章优先展示正文，空导语、段落标题与结尾不补模板；来源证据与限制在独立折叠区查看。视频文章和结构化报告的审校状态与发现独立展示，不混入正文。历史结果没有审校字段时保持未审校，不伪造通过状态。结构化报告保留指标、章节、要点与限制说明。文字创作展示文章、无标题短帖或说明文档正文，审校记录与材料引用默认收起。历史人工稿只读展示并说明原自动审校结论不适用。
- 普通文档整理沿用原文档分析配置器；`structured_report` 无媒体时直接用原报告入口阅读规范 Markdown，缺少报告文本时仅以实际章节正文／要点作为回退，不生成视频时长或媒体指标。文档引用保留服务端的原文哈希与区间，不能推断为真实出处核验已完成。
- 剧本分析展示故事概述、指标、优先修改、值得保留的部分、幕结构、关键转折、节奏、人物目标／冲突／弧与对白发现。未识别场景而使用 `unit-` 来源时，数量及分类显示为“文本单元”，不宣称场景覆盖。场景／文本单元细读按 10／20／50 分页，保留场景目的、冲突、变化、节奏与发现；改写展示服务端原有词汇表、修改摘要及完整报告。错误分“请求限流”与“额度耗尽”，只显示归类后的可行动信息。
- 本轮只接线既有 Skill 方法，不新增导航、页面、补充来源选择器或额外分享按钮。原表单保留 Skill、语言、自定义要求、恢复默认的布局与行为。未知请求回执与服务端 `analysis_outcome_unknown` 均禁止自动或盲目重发；先通过查询核对任务／运行，再由用户明确选择后续动作。创建幂等键只在收到确认响应后更新，取消与旧请求代次保护保持有效。
- 报告用维护中的 `flutter_markdown_plus` 渲染（`MarkdownBody` + 统一 `MarkdownStyleSheet`，文本可选择，引用与代码块只用轻量底色，不用常态描边，明暗自适应），视频与剧本共用 `AnalysisReportPreview`。报告状态可用且制品格式允许时，提供服务端 Markdown／DOCX／公众号 HTML／原生拉片 ZIP 导出；预览携带分析 ID，保存／系统分享通过 `exportAnalysisMarkdown` 取得服务端完整规范文本，再交给系统，避免只导出页面当前分类或拼接的摘要。

## 精确分析详情与运行记录

- `/analyses/:analysisId` 先 GET 分析历史记录，再以同一分析 ID 获取任务与结果；不按源素材查找“最新分析”，不因打开历史而创建新任务。标题保留素材名、Skill 与输出语言；可查看同素材全部处理记录，来源可用时提供源文件入口。
- 源文件不可用时保留历史结果／报告查看，禁用重新执行。重新执行前明确说明沿用原配置、保留任务 ID、增加运行次数且可能消耗额度；修改配置须从源文件新建分析。账号切换会使已打开的确认失效。
- 运行记录消费 `listAnalysisRuns`，以 `before_run_no` 游标分页，默认 10，可选 10／20／50；显示实际运行序号、状态、时间与失败原因，不捏造技术尝试号。活跃任务每 3 秒更新运行记录，任务轮询停止后记录也停止轮询；新运行重置分页。
- 同一运行从活跃态转为完成或取消时，停止定时轮询并额外读取一次运行记录，即使 `runNo` 未变化也更新终态。运行记录查询失败后停止自动请求，保留显式重试入口。
- 历史记录的取消请求标记用于禁用重复取消；重试／取消后刷新历史动作信息，删除后清空精确任务并刷新处理历史。

## 验证边界

精确记录控制器、结果联合渲染与结构化报告由合成测试覆盖，并提供原生截图夹具。真实 AI 执行、重试额度、运行历史跨端一致性与报告制品的真实下载／分享仍待联调，不将合成测试视为真实验收完成。

## 文字创作兼容范围

处理历史支持 `content_creation` 分类与对应 Skill 筛选，精确详情支持第六种结果契约。App 本轮支持服务端已创建文字任务的读取、报告预览与 Markdown／DOCX 导出；材料创建和报告历史回查由 Web／桌面端承担；所有分析结果只读，站内不提供人工编辑或保存；发布制品可用时，App 也通过鉴权的生成接口保存公众号 HTML 与原生拉片 ZIP；只展示服务端 metadata 中实际可用的文件按钮。HTML 不在 App 内执行，不引入 WebView；原生正文与镜头说明沿用既有报告 reader。拉片 ZIP 包含原生交互 HTML、镜头 JSON、运动曲线、首尾关键帧和联系表，原视频由用户在解压后另行选择。公众号排版预览与富文本复制由 Web／桌面端承担。生成客户端不单独引入 App 尚未实现的创建与修订操作。

本轮静态检查、单元／Widget 测试和 Android debug 构建通过。iOS arm64 模拟器构建通过；通用模拟器构建命令遇到 Flutter SDK 的双架构裁剪问题。真实文字任务已在 Web 使用当前 Provider 生成，不能据此认定 App 的真实鉴权、文件分享和模型工作流已完成设备验收。
