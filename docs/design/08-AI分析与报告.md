# AI 分析与报告

## AI 分析

- 视频与剧本共用控制器（`AnalysisTarget` 区分），契约：Skill 清单（`input_kind`）、创建、恢复、读取、取消、重试、删除，创建／重试使用稳定幂等键。
- 下载成功后才展示分析区；默认选中第一个 Skill，可选输出语言，编辑分析重点（≤ 4000 字）。分析状态独立于下载状态；活跃分析每 2 秒 REST 收敛；每次操作、Provider 重建或销毁使旧请求代次失效，旧结果不写回也不恢复轮询；`runNo/version` 不回退；已完成任务可重新分析并标识“上一版”结果。
- 结果按服务端判别联合渲染（视觉分析、视频文章、剧本各自分区；长结果一次一个分类，避免同时构建全部分镜）；错误分“请求限流”与“额度耗尽”，只显示归类后的可行动信息。
- 报告用维护中的 `flutter_markdown_plus` 渲染（`MarkdownBody` + 统一 `MarkdownStyleSheet`，文本可选择，引用与代码块只用轻量底色与左侧分隔，明暗自适应），视频与剧本共用 `AnalysisReportPreview`。支持 Markdown 保存／系统分享（“分享报告”）及服务端 DOCX 二进制导出（受报告状态与 artifact 格式限制）。
