# 视觉与交互

- **基线**：唯一视觉参照是 `video-server/frontend` 的 `radix-nova`、neutral 主题；App 使用 `shadcn_ui`：语义色（OKLCH 生成时转 sRGB，保留 alpha）、10pt 基础圆角、Geist 排版、统一间距。语义色同时驱动 ShadTheme 与仅供播放器／路由等底层的 Material 兼容主题，不允许第二套手写色板。
- **组件**：按钮、表单、选择器、提示、弹层、徽标、进度全部用 Shad 组件；持续错误 `ShadAlert`、操作反馈 `ShadSonner`、字段校验 `ShadInputFormField`、确认 `ShadDialog`、编辑面板 `ShadSheet`；Spinner／分页／导航由其按钮、进度与主题组合，缺口在业务辅助组件中明确记录，且业务辅助组件仅组合 Shad 组件。共享 `AppDropdownField` 承载弹层高度有界的选择（支持单项禁用）。
- **风格**：无边框连续画布，依靠留白与排版建立层级，不使用卡片墙、重阴影、渐变、装饰分隔线或描边按钮；页面标题使用本地化“帧取／Framegrab”文字品牌，图形 Logo 只用于应用图标与启动过渡。
- **品牌资产**：来源 `video-server/frontend/public/logo.svg|png`，App 保留 `assets/brand/{logo.svg,logo.png,app_icon.png}`；不重绘、不改色与构图。iOS 1024 商店图标为无透明通道的白色背景；Android 提供 mdpi–xxxhdpi、圆形与 API 26+ 自适应图标（前景在安全区内）；原生图标不随主题改变。验收图标时检查源文件、编译后 AppIcon 与“帧取”入口，不能凭其他应用的图标下结论。
- **媒体展示**：同一布局“宽度统一、高度自适应”——图片解码后按原比例铺满宽度，不固定高度、不拉伸、不裁切，竖图允许页面变长；内联视频按运行时真实宽高布局；尺寸未知时用可读占位。
- **播放**：`media_kit` + libmpv，MP4/H264/AAC 与 WebM/VP9/AV1/Opus 使用同一播放入口（播放、暂停、进度、全屏），解码或网络失败显示可重试错误；“获取文件”交付服务端保存的原始产物，不改扩展名伪装格式；页面销毁释放播放器。
- **文案**：以 Web 当前普通用户页面为文案基线，两端不同业务含义必须同步修正；英文保持同一语义，不逐字翻译；Web 不准确或过窄的文案一并修复。
- **平台差异（有意）**：底部导航替代 Web 移动 Sheet；系统字体替代自托管 Geist（保证动态字体）；系统返回、文件选择／保存、系统分享、安全存储、权限与触控目标遵循平台规范。禁止：不同色板、伪造格式／进度／平台状态、把 Web Cookie 当会话。
