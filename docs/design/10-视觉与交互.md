# 视觉与交互

- **基线**：唯一视觉参照是 `framefetch-server/frontend` 的 `radix-nova`、neutral 主题；App 使用 `shadcn_ui`：语义色（OKLCH 生成时转 sRGB，保留 alpha）、10pt 基础圆角、Geist 排版、统一间距。语义色同时驱动 ShadTheme 与仅供播放器／路由等底层的 Material 兼容主题，不允许第二套手写色板。
- **组件**：按钮、表单、选择器、提示、弹层、徽标、进度全部用 Shad 组件；页面级空状态及可恢复错误使用共享 `DataStateMessage`，操作反馈 `ShadSonner`、字段校验 `ShadInputFormField`、确认 `ShadDialog`、编辑面板 `ShadSheet`。共享 `AppDropdownField` 承载弹层高度有界的选择（支持单项禁用）。控件常态边框透明，输入/选择器使用 muted 填充，焦点与校验反馈保留。
- **对齐**：页面标题、正文、表单字段、列表名称与长说明左对齐；字段错误保留在对应字段附近。头像、账户身份聚合区、按钮内容和媒体视口按用途与使用体验布局，可居中。
- 独立数据块（统计数值、格式、时长、文件大小、时间及文档解析计数）的标签与数值在各自单元内成组居中；列表名称、文件名、长说明与报告段落保持左对齐，数值表格列右对齐。数据保持完整、可换行，原有可选择文本不取消选择能力。
- **状态布局**：页面级空态与恢复错误的图标、短标题和操作聚合居中，长说明左对齐；页面级纯等待态居中，局部加载指示按所在区域的用途布局。
- **加载与刷新**：页面等待统一使用 `AppLoading` 的居中 spinner，不使用矩形骨架占位或横跨页面的无限进度条；下拉刷新使用同一组件的紧凑模式，保留原生手势且不遮挡交互。已有数据刷新期间继续展示，刷新完成后恢复正常滚动位置。实际上传、下载和分析任务的确定进度继续使用进度条。
- **风格**：无边框连续画布，依靠留白与排版建立层级，不使用卡片墙、重阴影、渐变、装饰分隔线或描边按钮；导航使用与 Web 相同的图形 Logo 和本地化“帧取／Framefetch”文字品牌；大字体下文字可省略但保留完整读屏名称。
- **品牌资产**：来源 `framefetch-server/frontend/public/logo.svg|png`，App 保留 `assets/brand/{logo.svg,logo.png,app_icon.png}`；不重绘、不改色与构图。iOS 1024 商店图标为无透明通道的白色背景；Android 提供 mdpi–xxxhdpi、圆形与 API 26+ 自适应图标（前景在安全区内）；原生图标不随主题改变。验收图标时检查源文件、编译后 AppIcon 与“帧取”入口，不能凭其他应用的图标下结论。
- **媒体展示**：同一布局“宽度统一、高度自适应”——图片解码后按原比例铺满宽度，不固定高度、不拉伸、不裁切，竖图允许页面变长；内联视频按运行时真实宽高布局；尺寸未知时用可读占位。
- **播放**：`media_kit` + libmpv，MP4/H264/AAC 与 WebM/VP9/AV1/Opus 使用同一播放入口（播放、暂停、进度、全屏），解码或网络失败显示可重试错误；“获取文件”交付服务端保存的原始产物，不改扩展名伪装格式；页面销毁释放播放器。
- **文案**：以 Web 当前普通用户页面为文案基线，两端不同业务含义必须同步修正；英文保持同一语义，不逐字翻译；Web 不准确或过窄的文案一并修复。
- **信息密度**：业务页面去除重复导语、静态副标题、手势教学、空态长介绍与导航入口说明；不保留删除文案的占位间距。字段标签、真实元数据、状态、输入与权限约束、失败原因和确认仍按需显示。手势操作保留读屏语义；公开功能与指南正文继续提供有效信息。
- **平台差异（有意）**：底部导航替代 Web 工作区 Sheet；Geist 使用 shadcn_ui 打包字体并允许动态文字缩放与中文系统回退；系统返回、文件选择／保存、系统分享、安全存储、权限与触控目标遵循平台规范。禁止：不同色板、伪造格式／进度／平台状态、把 Web Cookie 当会话。
