# 帧取 App设计

本目录维护产品范围、业务规则、架构和验证条件。运行方式见 [README](../../README.md)，工程规范见 [PROJECT.md](../../PROJECT.md)，视觉规范见 [design.md](../../design.md)。

业务页面仅显示标题、操作、字段及实际内容，不常驻重复页面导语、列表手势提示或入口长介绍。必要的输入限制、权限约束、动态状态、错误恢复及删除确认保留；可见提示收敛不删除屏幕阅读器的控件语义。内容页保留真实指南与说明正文。

页面标题、正文、表单字段、列表名称与长说明左对齐；字段错误保留在对应字段附近。头像、账户身份聚合区、按钮内容和媒体视口按用途与使用体验布局，可居中。

独立数据块（统计数值、格式、时长、文件大小、时间及文档解析计数）的标签与数值在各自单元内成组居中；列表名称、文件名、长说明与报告段落保持左对齐，数值表格列右对齐。数据保持完整、可换行，原有可选择文本不取消选择能力。

页面级空态与恢复错误的图标、短标题和操作聚合居中，长说明左对齐；页面级纯等待态居中，局部加载指示按所在区域的用途布局。
- **加载与刷新**：页面等待统一使用 `AppLoading` 的居中 spinner，不使用矩形骨架占位或横跨页面的无限进度条；下拉刷新使用同一组件的紧凑模式，保留原生手势且不遮挡交互。已有数据刷新期间继续展示，刷新完成后恢复正常滚动位置。实际上传、下载和分析任务的确定进度继续使用进度条。
