# 帧取 App 设计文档

### 2026-10-02 Web 与服务端同步范围

App 以当前 `video-server/design.md`、Web 业务页面和服务端自动导出的 OpenAPI 为共同基准，继续使用 Flutter 原生组件、原生 Bearer 会话与系统文件交互。同步包括：

- 共享黑白灰语义色、无常态边框的控件与弹层、中性填充、紧凑页面标题、居中空状态与错误恢复、宽度自适应布局；触控目标与焦点/校验反馈仍保留。
- 解析结果按可用宽度切换双栏/单栏，完整展示格式信息；下载、剧本文档及统一处理记录共享搜索、筛选和 10/20/50 条分页，选择变化与批量操作保持 Web 语义。
- 统一处理记录覆盖链接解析、文档导入及视频/剧本分析，独立页面提供筛选和下一步操作；分析结果与报告完整消费当前服务端字段。
- 个人资料同步用户名、头像读取/上传/删除和只读账户字段；使用指南、自托管部署与关于入口对匿名及登录用户可达。
- 管理中心同步系统操作日志、下载/AI 分析统计、用户配额和删除、文件删除、平台目录与 AI 配置筛选/分页/批量操作。OpenRouter 模型与引擎能力来自服务端，不猜测默认 CLI 模型或费用。
- 经白名单审查后同步头像、统一历史、分析运行/报告、媒体导入、引擎与 OpenRouter 模型、日志、AI 统计及管理删除接口；不引入 Web Cookie 认证。

以上是本次实现与验证目标。格式、静态分析、单元/Widget 测试与 Android/iOS 构建属于确定性证据；真实鉴权、上传、下载、Provider 和 AI 执行仍须使用同版本服务端与模拟器/真机验证，不能由 Mock 或生成客户端替代。

首页解析记录的标题按按钮可用宽度限制为两行，超长内容以省略号呈现，按钮高度随文字缩放适配；显示截断不改变原始标题或恢复记录的目标。

### 解析引擎 R0 契约清理

服务端设计 17 删除平台会话、治理证据与解析策略管控。App 删除平台运行诊断、访问策略选择与对应接口白名单，平台目录仅展示接入情况和 Registry 身份要求；解析失败消费服务端的 13 类失败及 layer/stage/gate/evidence/summary，身份不可用和上下文变化提示重新解析，限流显示稍后重试，不保留会话自动恢复投影。客户端继续由服务端 OpenAPI 经本仓库白名单裁剪生成。验收条件：`flutter analyze`、`flutter test` 通过，并与同版本服务端联调。平台解析与下载验收由服务端设计 17 负责。

### 解析引擎 P1 只读上下文

InspectionResponse 与 DownloadResponse 从服务端 OpenAPI 生成可空、只读的 `execution_context`，包含设计 17 第 3.7 节十二个非敏感字段。App 可读取实际层级、客户端、引擎与出口摘要，不接收 Cookie 或浏览器句柄；本地导入或尚未执行的下载可为 null。生成客户端的字段反序列化由契约单测覆盖；本次只更新 REST 契约，不构成 App 真机平台验收。

### prefer 身份契约

平台目录的身份枚举由服务端 OpenAPI 生成 `none / prefer / required`；prefer 表示解析优先复用已登录 Chrome 会话，身份不可用时匿名继续，下载保持解析时的身份选择。App 仅消费非敏感声明与十二字段 ExecutionContext，扩展材料不进入 App。客户端生成、格式、分析和测试为确定性契约证据，不能替代服务端登录平台或 App 真机验收。
