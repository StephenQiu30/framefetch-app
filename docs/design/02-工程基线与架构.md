# 工程基线与架构

## 平台与工程基线

| 项 | 基线 |
| --- | --- |
| 工具链 | Flutter 3.44.7、Dart 3.12.2、JDK 21、Xcode 27 |
| iOS | 最低 16.0（Runner 与所有 Pods 统一）；Swift；CocoaPods（`media_kit` 尚不支持 SPM，故关闭 Flutter SPM） |
| Android | 最低 API 24；Kotlin；JVM target 17；发布签名只由可信发布环境注入，不回退 debug key |
| 标识 | Bundle／Application ID `com.stephenqiu.framegrab`，显示名“帧取”；商店发布前复核标识所有权 |
| 状态与路由 | Riverpod 3、go_router（声明式路由，深链接与认证重定向） |
| 网络与契约 | Dio；OpenAPI Generator `dart-dio` 只读生成包 `packages/framefetch_server_api` |
| 凭据 | flutter_secure_storage 10.3.1（11.x 需 Android `compileSdk 37`，待工具链对齐后单独评审） |
| UI | shadcn_ui 0.57.x + Phosphor Icons；语义 Token 位于 `lib/core/theme/` |
| 播放与文件 | media_kit／libmpv、file_selector、shared_preferences（仅非敏感偏好） |
| 本地化 | Flutter ARB，`zh` / `en`，所有面向用户的文本进入 ARB |
| 验证 | flutter_test、integration_test、Golden、flutter analyze |

代码结构为 feature-first 混合：

```text
lib/
├── app/       入口、依赖装配、路由与生命周期
├── core/      config / network / routing / security / theme
├── features/  auth · download · history · documents · upload · analysis · media
│              providers · account · admin · landing · settings · foundation
└── shared/    多 feature 复用的 models / presentation / widgets
```

依赖方向 `presentation → view model / application → repository → service`；只有多 repository 编排或复杂规则出现才增加独立 domain 层；feature 不直接导入其他 feature 的内部文件。禁止并存第二套状态管理、第二个 HTTP 客户端或平行手写 DTO。
