# 安全与隐私

- Access Token 不持久化；Refresh Credential 仅进系统安全存储；日志、崩溃与分析事件不含敏感数据或用户媒体；生产禁止请求体日志。
- 预签名 URL、短时下载地址、Provider 密钥、完整媒体 URL 不写日志、不长期缓存；私有封面不落长期缓存。
- 错误不展示内部异常、完整 URL 或 Provider Secret；每类错误提供准确说明与安全恢复动作。
- 离线：不提供离线业务能力；断网可保留最近一次非敏感只读状态并标记陈旧，恢复后重新拉取。
- 后台：进入后台暂停非必要轮询，回前台节流收敛。
- 临时文件写入沙箱，完整性检查后交给系统保存／分享；取消、失败、退出登录、空间不足时清理。
